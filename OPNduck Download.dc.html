SYSTEM REQUIREMENTS
GPU
NVIDIA, AMD, or Intel — used when present. Not required.
No GPU
Falls back to CPU. Slower — physics still applies, subscriptions don't change it either.
RAM
8GB minimum, more headroom helps with larger source files.
Disk
Room for AI models plus your working files. Exact footprint is still moving.
OS
Linux (primary), Windows (supported). No macOS build.
