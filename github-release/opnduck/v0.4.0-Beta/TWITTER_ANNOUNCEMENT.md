## 1. Main tweet

OPNduck v0.4.0 Beta is out! 🦆 Free, open-source, local-first media suite: 8K downloads, auto-download subscriptions, AI vocal removal, subtitles, upscaling. Nothing gets uploaded. Beta, so expect bugs. https://github.com/Sight8218/OPNduck/releases/tag/v0.4.0-Beta

## 2. Thread

1/ Downloader power-ups: 8K and 1440p, subtitles in any language (.srt), dubbed audio tracks as separate MP3s, whole channels, search results, Watch Later and Liked lists. Smart mode remembers your choices.

2/ Subscriptions: pick a channel or playlist and OPNduck downloads new uploads for you while it is open. Only future uploads by default, failures retry, and you get a desktop notification.

3/ New AI Audio card (Demucs): remove vocals, extract vocals, isolate a voice, basic echo and noise cleanup. Audio or video in. Heads up: the Python install is big, about 5.5 GB with CUDA libs.

4/ Library got real management: search, filters, sorting, batch groups with Cancel all and Retry failed, JSON export/import. Plus sign-in for private content via browser cookies or a built-in window.

5/ Much faster UI too: idle went from ~103 to ~200 fps, page switches from ~60 to ~160 fps. Still Electron: the Tauri move is postponed because WebKitGTK stutters on NVIDIA + Wayland.

6/ This is a Beta: expect bugs. Windows installers are built from Linux and untested on real Windows. Found something? Report it on GitHub. Free and GPL-3.0. https://github.com/Sight8218/OPNduck/releases/tag/v0.4.0-Beta
