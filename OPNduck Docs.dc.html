Getting started

OPNduck is pre-alpha software. Things will change, break, and get renamed. These docs describe how it's meant to work today — if something here doesn't match reality, the reality is probably a bug, so file an issue.

Everything runs on your machine. No account, no cloud, no telemetry. If a step here asks you to log in anywhere, it's wrong.

Installation

There's no signed installer yet. For the pre-alpha you clone and run from source.

Linux
git clone https://github.com/Sight8218/OPNduck cd OPNduck ./setup.sh # pulls model weights + ffmpeg python -m opnduck
Windows
git clone https://github.com/Sight8218/OPNduck cd OPNduck setup.bat python -m opnduck

Exact commands may differ between commits — always check the repo README for the current entry point.

Building from source

You'll need Python 3.10+, git, and ffmpeg on your PATH. The setup script fetches model weights on first run — expect a few GB.

python -m venv .venv source .venv/bin/activate # Windows: .venv\Scripts\activate pip install -r requirements.txt python -m opnduck --check # verifies GPU + ffmpeg

If --check reports no GPU, OPNduck still runs on CPU — just slower.
